# Privacy policy — It's a Lemon

Public hosting for the privacy policy of the iOS app
[It's a Lemon](https://apps.apple.com/app/id0000000000), served via GitHub Pages
at <https://sharkedup.github.io/lemon-privacy/>.

This repository exists only so the policy URL referenced by the App Store
listing stays publicly reachable. The app's source lives in a separate,
private repository.
